# Devika TD Portfolio

A responsive portfolio built with Next.js, TypeScript, Tailwind CSS, shadcn-compatible UI primitives, and Lucide icons.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The portfolio content is typed and centralized in `src/data/portfolio.ts`. The page uses the Next.js App Router under `src/app`, Tailwind utility classes for styling, and reusable UI primitives in `src/components/ui`.
